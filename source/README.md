# Jodo Shinshu Logical Model — Josuke Inoue

Machine-readable axioms and contrast tables extracted from the monthly dharma talks of **Honpa Hongwanji Mogi das Cruzes**.

| | |
|---|---|
| **Author** | Josuke Inoue (釋 穣信) — Kaikyoshi / Resident Minister |
| **Canonical site** | https://hongwanjimogi.org.br/source.php |
| **Sermons** | https://hongwanjimogi.org.br/howa.php |
| **License** | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |

This folder is not human-facing essay prose. It publishes:

1. Numbered axioms (`model-*.md`) — statement, negation, source sermon
2. Contrast rows (`contrast-*.md`) — conventional formula vs this reading vs logical failure

Languages: Japanese (`ja`), Portuguese (`pt`), English (`en`), Spanish (`es`).

Source of truth: [`logic.json`](logic.json) on the website repository, generated by:

```bash
python howa/Github/generate_source_markdown.py
```
